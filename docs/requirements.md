# FileHarbor — Requirements

## Objective

Build a cloud-based document management application
using Angular, Spring Boot and Azure Blob Storage.

## Functional Requirements

- FR-01: Upload documents.
- FR-02: Display uploaded documents.
- FR-03: Download documents.
- FR-04: Delete documents.
- FR-05: Display document metadata.

## Non-Functional Requirements

- NFR-01: Validate uploaded files.
- NFR-02: Protect storage credentials.
- NFR-03: Use Azure Managed Identity in production.
- NFR-04: Provide meaningful API error responses.
- NFR-05: Include automated tests.
- NFR-06: Support secure access to file operations.

## Out of Scope — Initial MVP

- Document sharing.
- Document versioning.
- Folder management.
- Advanced search.
- Multi-tenant functionality.
